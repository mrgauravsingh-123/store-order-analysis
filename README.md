# Store Orders Analysis Project

# Problem Statement
To analyze factors affecting profit and predict whether an order will result in profit or loss.

# Tools Used
- Power BI (Data Visualization)
- SPSS Modeler (Predictive Modeling)

# Process
1. Data Cleaning
2. Data Analysis
3. Modeling
4. Prediction

# Key Insights
- Discount negatively impacts profit
- Sales alone do not guarantee profit
- Regional differences affect performance

# Conclusion
Optimizing discount strategies can improve profitability.
